# Сравнение quickstart с поиском минимума

[English](../quickstart-comparison.md) · [Текущий quickstart](getting-started.md)

Оба полных примера используют одинаковые данные [7,3,5,2,6], поиск минимума за
один проход, операции createArrayTrace и штатный Canvas-рендерер. Оба сохраняют
явный итог «Minimum: 2» и зелёный столбец найденного минимума.
Алгоритм делает четыре сравнения и ни одной записи массива; порядок не меняется.

## Что новичок узнаёт в обоих случаях

Цикл и условие сравнения принадлежат алгоритму. compare записывает видимое
сравнение и увеличивает счётчик; результат упорядочивания он не возвращает.
highlight отмечает текущего кандидата. start/done ограничивают trace. Неизменяемые
снимки и стабильные ID элементов создаёт trace; рисование Canvas делегировано.

Генератор выводит Searching… в начале и итог перед yield done, используя
свой индекс min. Render только рисует Canvas; хранить результат или историю
подсветки не требуется. Этот пример идёт только вперёд. Аннотации с seek должны
входить в прикладное состояние каждого кадра.

Вход здесь фиксированный и непустой. done({ result: [min] }) записывает ответ;
один штатный рендерер оставляет выбранный столбец зелёным. Собственный финальный
снимок, второй рендерер, преобразование события и поиск значения по ID не нужны.

## Выбор главного примера

Player остаётся главным: стандартные Start, Next и Restart при прямом подключении
Canvas-рендерера через stepSource. isTerminal явно распознаёт done. Вариант createArrayPlayer
полезен как учебный этап с одной собственной кнопкой, pre — как ввод в произвольный вывод.

[Реализованный контракт](player-step-source.md) доступен локально, ещё не опубликован.
В опубликованной 0.16.0 такого API нет; команды установки локального архива даны
в quickstart. Историческое сравнение до stepSource давало 54/47 строк и требовало
адаптер кадра и EOF-клик у Player; эти ограничения теперь сняты.

**Реализовано локально:** [done({ result })](array-result.md) заменил прежний код
финальной подсветки (43/45 строк). Упрощение для фиксированного непустого массива
сократило оба варианта до 31 строки. Возможность ещё не опубликована.

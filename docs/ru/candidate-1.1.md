## Состав и миграция

По сравнению с выпущенной 1.0.0 / 3977c78 добавлены два независимых ESM-пути:
/graph (createGraphTrace, graphScene) и /canvas/graph (createGraphRenderer).
Всего десять entry, 24 runtime-имени и 95 type-only экспортов (83 различных).
Фиксированная топология, стабильные ID, отметки, результат, подписи в снимке,
атомарная валидация и граница Canvas определены в [Graph API](graph-api.md).
Алгоритмы и вычисление раскладки принадлежат приложению. BFS представлен двумя
примерами репозитория; экспорт алгоритма в пакет не добавлен.

**Для восьми прежних импортов миграция не нужна.** Файлы реализаций, export-map
записи, runtime-зависимости и версии компиляторов прежние. Новых controls/options
Player, root import, CommonJS или обещания поддержки браузеров нет. Новые графовые
entry получают общую политику совместимости 1.x при первой публикации. Если
безопасного места для подписи нет, Canvas вправе её пропустить.

Графовые импорты требуют 1.1.0; опубликованная 1.0.0 их не содержит. До публикации
нужна локальная сборка/архив. Quickstart поиска минимума намеренно закреплён на
опубликованной npm 1.0.0 и не использует графовые entry.

## Проверки и оставшиеся шаги

[Отчёт подготовки кандидата](../checks/candidate-1.1.0-2026-11-17.json) фиксирует
свежие repository tests, проверку версионированного архива/потребителей, изоляцию
bundle и хеши файлов. Прежние native-доказательства сохранены по совпадению
исходников: 31 проверка реального Canvas и семь проверок страницы BFS. Новый
браузерный прогон или performance benchmark для версии/документации не заявляется.

После локального acceptance нужно закоммитить/отправить проверенные исходники,
тесты, примеры, изображения и документацию. Все 11 jobs должны успешно завершиться
на этом точном коммите: Node 22/24/26 × Ubuntu/Windows (6), четыре TypeScript
consumer jobs (4), bundle isolation (1). Старый CI 1.0.0 или другого SHA не подходит.

Только затем отдельно порученный этап может создать v1.1.0 и стабильный GitHub
Release, дождаться OIDC-публикации npm и проверить точную версию, обычный latest и
provenance/source SHA. Workflow публикации сам не проверяет этот предшествующий
барьер из 11 CI jobs.

# Документационный патч 1.3.1

[English](../release-1.3.1.md) · [Текущий API](current-api.md) · [Завершённый релиз 1.3.0](release-1.3.md)

Версия **1.3.1** согласует EN/RU README, changelog, справочники API/окружений и
статусы релиза с завершённой публикацией 1.3.0. Добавлен [фактический отчёт 1.3.0](../releases/1.3.0.json),
ссылки на кандидата в текущих справочниках заменены релизными; отчёты подготовки
и проектирования явно отмечены как исторические.

Runtime-исходники, декларации, все 14 экспортируемых путей, зависимости и примеры
сохранены из 1.3.0. Миграция не нужна. /grid и /canvas/grid доступны с 1.3.0;
воспроизводимый quickstart поиска минимума остаётся на точной версии 1.0.0,
которая уже содержит используемые возможности.

Неизменяемый npm-пакет содержит исправленные EN/RU README и changelog.
Проверки публикации самой 1.3.1 фиксируются отдельно по факту их завершения;
связанный отчёт 1.3.0 подтверждает только предыдущий релиз.

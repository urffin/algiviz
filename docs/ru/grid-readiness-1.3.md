# Готовность /grid и /canvas/grid к 1.3.0

[English](../grid-readiness-1.3.md) · [Текущий API](current-api.md) · [Grid API](grid-api.md) · [Grid Canvas](grid-canvas-api.md) · [Пример BFS](examples.md#кратчайший-путь-bfs-на-сетке) · [Машинная ревизия](../checks/grid-readiness-1.3-2026-11-20.json)

**Подготовка кандидата, 2026-11-20:** package.json и оба корневых поля lockfile
теперь содержат 1.3.0. [Заметки кандидата](candidate-1.3.md) и
[отчёт подготовки](../checks/candidate-1.3.0-2026-11-20.json) заменяют прежние
сведения о версии и R1/R2. R3 проверяется после commit/push на итоговом SHA;
R4 (тег/публикация) не входит в эту задачу. Датированные этапы ниже исторические.

**Ревизия 2026-11-20; локально, без публикации.** /grid и /canvas/grid готовы к
подготовке кандидата в границах приведённых контрактов. Открытых решений API и
известных блокеров реализации не найдено. D1 (список импортов README) и D2
(различение Scene/SceneFrame в описании get) исправлены в EN/RU. R0 завершён; R1–R4 ещё открыты. Эта ревизия меняет только
документацию: реализация, API, версия и lockfile прежние; коммит, push, CI, тег,
Release и публикация не выполняются.

## Объём и выбор версии

Зафиксированная выпущенная база — **1.2.1 / c398d2d**, документационный патч к
1.2.0. Все 53 исходника реализации и двенадцать export-map записей сохранены;
декларации двенадцати публичных entry побайтно совпадают с установленным архивом
1.2.1. Добавлены независимые entry, поэтому **1.3.0 — совместимый minor-ориентир**.
Package.json и оба корневых поля версии lockfile пока содержат 1.2.1.

| Поверхность | Выпущенная 1.2.1 | Рабочая копия |
| --- | ---: | ---: |
| Entry paths | 12 | 14 |
| Runtime-имён | 27 | 30 |
| Type-only экспортов | 128 | 155 |
| Различных type-only имён | 116 | 143 |

/grid экспортирует createGridTrace, gridScene и 22 типа. /canvas/grid —
createGridRenderer и пять типов. Прежним импортам миграция не нужна. Новые grid
импорты потребуют 1.3.0 после публикации; в npm 1.2.1 нет обоих entry. С первого
выпуска действует общая защита совместимости 1.x, без experimental-уровня.
Зависимости, build-инструменты и прежний Player API не меняются.

Второй generic GridFrame — Event. Четыре варианта GridEvent, два вида GridObjects
и enums renderer — закрытые наборы; роли — открытые строки. Не добавляются
root/CJS/private deep imports, новые controls Player, встроенный BFS, модель
стен лабиринта, sparse grid, edit формы, SVG или OffscreenCanvas backend.

В проверенном объёме открытых технических блокеров нет. Пределы размеров —
валидация, не гарантия времени кадра или памяти. Opaque values принадлежат
приложению. Result.path не проверяет соседство, стены и кратчайший маршрут:
эти правила принадлежат алгоритму BFS в примере.

## D1: исправлен список импортов README

Абзацы установки перечисляли десять импортов без выпущенных /tree и
/canvas/tree, хотя таблицы модулей содержали двенадцать. В EN/RU теперь перечислены
все двенадцать опубликованных путей. Grid entry явно остаются локальными и
неопубликованными, с требованием локальной сборки/архива. Выпущенные архивы и
исторические JSON не переписываются; новых package API эта правка не добавляет.

## D2: уточнено различие Scene и SceneFrame

В описании проекции теперь явно указано: gridScene возвращает Scene с objects;
get(id) предоставляет SceneFrame после createSceneFrame или при dispatch.
Прежняя краткая формулировка scene.get могла подразумевать метод на результате
gridScene. Декларации и реализация уже соответствовали этому разделению.

## Проверки и переиспользование доказательств

- **708/708 тестов репозитория**, включая 30 grid, 23 Grid Canvas и семь групп
  BFS-регрессий. Пример проверен на **672** сочетаниях препятствий и открытых
  endpoints независимой многократной релаксацией рёбер. Успешный прогон
  переиспользован после сверки хэшей исходников, тестов и примера; ссылки и
  списки импортов дополнительно проверены статически в этой ревизии.
- Свежий установленный пакет: **TypeScript 6.0.3**, NodeNext и Bundler,
  **456 runtime-регрессий**. Consumers для **5.0.4, 5.4.5 и 5.9.3** в обоих
  режимах разрешения переиспользованы для неизменных исходников, деклараций и
  fixtures. Эти 456 проверок не включают прикладные примеры: они не входят в npm.
- **42 варианта сборок** переиспользованы после сверки скриптов, исходников и
  отчёта. Независимые/lazy grid entry не загружают другие backend, посторонние
  импорты не получают grid code. Это проверка изоляции, не обещание скорости.
- Native-приёмка переиспользована для неизменных реализации, compiled runtime
  и fixtures: **18 renderer-проверок**, включая 12 сочетаний theme/size/backing
  ratio × четыре progress, и **23 UI-проверки BFS/примеров** на 960/390 px.
  Явные backing ratios renderer — 1/1.25/2; фактический DPR host записан отдельно.
  Проверены Canvas pixels, разделение текста/пути, зелёный результат, rewind/seek,
  Restart, resize/DPR, host errors и cleanup. Пример также проверяет прежние
  результаты BFS/DFS лабиринта. BFcache handlers проверяются отправкой persisted
  pagehide/pageshow; пригодность страницы для browser cache не сертифицируется.
- Свежая проверка локального архива: **131 файл, 126 dist-файлов**, включая
  12 headless grid и восемь Grid Canvas. Версия пакета пока 1.2.1; тестовый архив
  рабочей копии не является выпущенным архивом 1.2.1 или кандидатом 1.3.0.
  Примеры/тесты/скрипты не упакованы. EN/RU README и changelog архива сверены с
  текущими exports и документацией исходников.

Прежним двенадцати импортам миграция не нужна. С текстом версии примера обновить его status assertions. Не заявлять невыполненные проверки публикации. | Ожидает |

Release workflow проверяет согласованность версий и пакет/тесты, но не требует
завершения прежних одиннадцати CI jobs. **R3 должен пройти до R4.** CI версии
1.2.1 не сертифицирует эти незакоммиченные изменения. Правки одной документации
не требуют повторять неизменное native-поведение; изменения реализации или
fixtures оцениваются относительно хэшей соответствующей приёмки.

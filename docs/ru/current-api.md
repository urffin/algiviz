F1/F2/U1/U2 не меняют публичные сигнатуры/экспорты. На этапе F2 проверка дала
**509 успешных тестов репозитория**. Три родительских теста запускают **121

Публичны ESM-пути export map; root/CommonJS и внутренние deep paths вне
поддерживаемой поверхности. Lib деклараций и активные runtime-host различаются:
headless ES2022, DOM для Canvas/виджета/host, отдельно WebWorker для endpoint.
[Политика окружений U3](api-compatibility.md#окружения-и-загрузка) сохраняет
проверенную границу без нового обещания браузера/версии. Optional-загрузка не
делает entry экспериментальным. Host и endpoint используют одинаковую версию
пакета; wire format приватен.

## Как читать исторические доказательства

- `releases/` подтверждает указанную опубликованную версию/SHA, а не последующие
  локальные правки. Опубликованная 0.16.0 имела **304** теста репозитория.
- `checks/` фиксирует названный audit/design/implementation-этап и хэши.
  Например, на этапе U1 было **373** теста, позднее на U2 — **428**. Исходная
  таблица ревизии восьми entry намеренно остаётся срезом 0.16.0.
- Benchmark JSON и paired-performance отчёты сохраняют исходные хэши, workloads
  и числа. Scene cache и dispatcher reuse были unreleased при измерениях от базы
  0.13.0 и затем опубликованы в 0.14.0.
- Старые export/array/Canvas/minimal-аудиты и design-stage проверки деклараций —
  исторические выводы/результаты, а не новые числа и не отсутствующая реализация.
- Mock-транспорт, Node Canvas stub, native browser, установленный архив и CI
  точного релиза подтверждают только записанный объём. U4 не добавляет таких
  runtime-результатов и не расширяет список окружений.

При оценке рабочего дерева текущий контракт/статус имеет приоритет над языком
планирования отдельного прошлого этапа. Исторические числа и raw results
сохраняются. U5 выбран и покрыт постоянными регрессиями локально; F2 исправлен
и постоянно проверяется. [Текущий список условий](candidate-1.0.md#оставшиеся-релизные-условия)
фиксирует G1/G2 и выбранный G3 на 76f76ed; остаются документация свидетельств
и отдельно порученная публикация.
Этот этап не запускает релиз.

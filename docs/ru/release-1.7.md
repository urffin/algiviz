# AlgiViz 1.7.0

[English](../release-1.7.md) · [Текущий API](current-api.md) · [Окружения](../support-matrix.md#current-support-boundary)

AlgiViz 1.7.0 добавляет `stepHistory` в `Player`. Синхронная фабрика
возвращает непустой массив явных шагов без пропусков. Запись хранит событие
и исходный индекс каждого шага. При перемотке `frame.event` и
`frame.stepIndex` относятся к шагу, состояние которого лежит в `frame.current`.
[Полная история шагов](player.md#полная-история-шагов).

Restart вызывает фабрику заново. При ошибке фабрики или валидации
воспроизведение останавливается, а прежняя запись, позиция и кадр остаются
доступны. `onError` получает исходную ошибку.

В [браузерной проверке сортировки пузырьком](../../test/step-history-array-browser.html)
кадр передаётся напрямую штатному Canvas-рендереру для подсветки обмена
при перемотке. В [примере пирамидальной сортировки](examples.md#пирамидальная-сортировка-с-player)
`stepHistory` синхронизирует массив и дерево в одном Player. Кадр хранит
событие кучи, а панель массива берёт своё событие из общего снимка.
[Две панели в одном Player](player-multiple-panels.md).

## Совместимость и окружения

Объект опций новой перегрузки конструктора можно типизировать через
`PlayerStepHistoryOptions<State, Event>` из `/player`. Конструктор принимает
все четыре прежние ветки `PlayerOptions`, включая `history`, где
`frame.event` равен `undefined`. Прежнее сужение и вывод типов сохраняются.

У пакета 16 точек входа ESM и нет зависимостей времени выполнения.
Новая опция использует существующие требования `/player` к DOM и времени
воспроизведения. Примеры и браузерные проверки находятся в репозитории.

# Готовность списка к 1.4.0

[English](../list-readiness-1.4.md) · [API списка](list-api.md) · [Canvas API](list-canvas-api.md) · [Пример](examples.md#операции-со-связным-списком) · [Отчёт проверки](../checks/list-readiness-1.4-2026-11-20.json)

**Историческая ревизия от 20 ноября 2026 года.** [Заметки к 1.4.0](release-1.4.md) описывают версию пакета.

Ревизия сверяет новые локальные модули `/list` и `/canvas/list` с опубликованной
1.3.1. В рабочей копии 16 точек входа, 33 runtime-экспорта и 185 экспортов типов
(173 различных имени). Прежние 14 записей экспорта, их скомпилированный код и
декларации совпадают с опубликованным пакетом. Миграция прежних импортов не нужна.
Отдельные точки входа подходят для совместимого minor-релиза 1.4.0.
[Политика совместимости](api-compatibility.md)

| Раздел | Проверенное поведение |
| --- | --- |
| Модель списка | ID узлов и структурные ID слотов head/next, полная цепочка без циклов, запрет возврата выбывших ID, атомарный edit и независимый результат |
| Раскладка Canvas | Позиции из снимка, постоянный head, отключаемые null-маркеры и отступы с учётом стрелок и обводки |
| Интерполяция | Прежняя и новая стрелки разрешают собственные цели. Сохранённые слоты сохраняют ID, в том числе при переходах из null и обратно |
| Отрисовка | Подгонка текста, цвета результата, восстановление состояния контекста и bitmap/DPR под управлением приложения |
| Пример | Вставка 5 после 7, удаление 3 и разворот до 9 → 5 → 7. Оба режима Player воспроизводят зелёный итог, Restart восстанавливает исходную цепочку |
| Пакет | Отдельные headless- и DOM-проверки, закрытые внутренние пути, независимые статические и ленивые импорты |

В ходе ревизии исправлена читаемость выбранного null-маркера. Обводка и стрелка
сохраняют цвет результата, подпись использует обычный цвет текста поверх фона
Canvas. У бейджа head текст результата остаётся поверх зелёной заливки.
Регрессия проверяет обе темы. В таблицах EN/RU README отдельно обозначены
14 опубликованных импортов и два локальных.

[Отчёт](../checks/list-readiness-1.4-2026-11-20.json) фиксирует архив, сверку кода,
тесты и наблюдения браузера. Ранее записанные проверки
[рендерера](../checks/list-canvas-implementation-2026-11-20.json) и
[примера](../checks/list-player-example-2026-11-20.json) сохраняют исходный объём.
Архив для этой ревизии был собран с рабочей версией 1.3.1.

Шаги выпуска, намеченные в ходе ревизии.

1. Подготовить кандидат 1.4.0. Обновить версию пакета и lockfile, оформить
   заметки выпуска и указать доступность 1.4.0 в обоих README и справочниках.
2. Проверить точный архив 1.4.0, закоммитить и отправить кандидат, затем
   дождаться всех 11 CI jobs на его коммите.
3. Выпустить проверенный коммит. Проверить версию в npm, latest, provenance
   и README registry, затем записать фактические результаты в EN/RU документацию.

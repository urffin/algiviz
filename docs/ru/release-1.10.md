# AlgiViz 1.10.0

[English](../release-1.10.md) · [Текущий API](current-api.md) · [Окружения](../support-matrix.md#current-support-boundary)

AlgiViz 1.10.0 добавляет настройки отрисовки рёбер графа и узлов дерева
в штатные Canvas-рендереры. В пакете 16 точек входа ESM. Зависимостей
времени выполнения нет.

## Граф

- `drawEdge` позволяет нарисовать ребро по рассчитанной кривой и вершинам
  наконечника. Необязательные функции `drawStroke()` и `drawArrow()` рисуют
  линию с пунктиром и залитый наконечник.
- `edgeBend` задаёт изгиб со знаком до отрисовки. Рендерер использует одну
  кривую для линии, наконечника и размещения подписи.
- `nodeRadius` задаёт желаемый радиус узла в логических пикселях. Радиус
  ограничен одной восьмой меньшей стороны области рисования.

[Настройка для Ахо — Корасика](graph-api.md#пользовательская-отрисовка-ребра)
сочетает эти опции с авторазмещением подписей. Суффиксные ссылки остаются
пунктирными при смене цвета активного ребра.

## Дерево

- `drawNode` позволяет нарисовать тело узла целиком или добавить деталь
  поверх `drawDefault()`.
- Четвёртый аргумент `render` принимает `doubleOutlineNodeIds`. Концы слов
  в Trie сохраняют кольца, когда они активны или лежат на подсвеченном пути.
- Опция `nodeRadius` задаёт размер узла и учитывается при расчёте мест
  крепления связей, двойного контура и подписей.

[Пример для Trie](tree-canvas-api.md#двойной-контур-конца-слова-в-префиксном-дереве)
получает ID концов слов из кадра. При перемотке через `stepHistory`
двойные контуры восстанавливаются вместе с кадром.

# AlgiViz 1.2.1: документационный патч

[English](../release-1.2.1.md) · [Changelog](../../CHANGELOG.md) · [Текущий API](current-api.md) · [GitHub Release](https://github.com/urffin/algiviz/releases/tag/v1.2.1)

Патч обновляет EN/RU README и changelog внутри пакета и согласует документацию
репозитория с завершённым выпуском 1.2.0. В архиве 1.2.0 сохранился устаревший
статус кандидата; файлы опубликованной версии заменить нельзя. Версия 1.2.1
содержит исправление для новых установок.

Реализации, публичные декларации, все двенадцать export paths, зависимости и
требования к окружениям не меняются относительно 1.2.0 / 8e1f50b. Прежним импортам
миграция не нужна. `/tree` и `/canvas/tree` доступны с 1.2.0; штатные и собственные
примеры сохранены.

Будущий [Grid API](grid-api.md) — проектная документация репозитория. `/grid` и
`/canvas/grid` этим патчем не реализуются и не экспортируются. В npm files не
добавляются алгоритмы или дополнительные каталоги документации. Пакетный README
ссылается на подробные EN/RU-справочники репозитория.

```sh
npm install @grundyjs/algiviz@1.2.1
```

[Отчёт 1.2.0](../releases/1.2.0.json) фиксирует CI, exact-version/latest и
криптографическую provenance завершённого выпуска. Исторический объём сохранён.
Документационный патч использует тот же GitHub Release → OIDC npm workflow:
CI точного коммита до выпуска и независимые проверки npm, README внутри архива
и provenance после публикации.

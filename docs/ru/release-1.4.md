# AlgiViz 1.4.0

[English](../release-1.4.md) · [Текущий API](current-api.md) · [Окружения](../support-matrix.md#current-support-boundary)

AlgiViz 1.4.0 добавляет две независимые точки входа для односвязных списков.

- [`/list`](list-api.md) предоставляет `createListTrace` и `listScene`. Каждый шаг
  записывает полную ациклическую цепочку. ID узлов и слотов head и next стабильны.
  Изменения проверяются атомарно. К шагам можно добавлять подписи и отметки результата.
- [`/canvas/list`](list-canvas-api.md) предоставляет `createListRenderer`. Он
  анимирует смену целей указателей между снимками, рисует head и null, выделяет
  узлы и указатели независимо. Размером bitmap и DPR управляет приложение.
- [Пример списка](examples.md#операции-со-связным-списком) показывает вставку,
  удаление и разворот с Player. В конце цепочка выделена зелёным. Доступны
  ограниченная перемотка и переходы по полной истории. Алгоритм и страница
  примера находятся в репозитории.

## Миграция и окружения

Прежним импортам миграция не нужна. Код, декларации и требования к окружению
для предыдущих 14 точек входа сохранены. Для `/list` достаточно деклараций
ES2022. Для `/canvas/list` требуются декларации DOM и контекст HTML Canvas 2D
при отрисовке. Пакет содержит 16 точек входа ESM и не имеет зависимостей времени выполнения.

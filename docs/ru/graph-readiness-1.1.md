## Объём и выбор версии

База сравнения — выпущенная 1.0.0 / 3977c78. Все 35 прежних файлов исходников и
восемь прежних export-map записей неизменны. Runtime-зависимости и версии build
инструментов прежние. Добавляются два независимых пути: **1.1.0 подходит как minor**,
без breaking-изменений прежних модулей.

| Поверхность | База 1.0.0 | Рабочее дерево |
| --- | ---: | ---: |
| Entry paths | 8 | 10 |
| Runtime-имён | 21 | 24 |
| Type-only экспортов | 69 | 95 |
| Различных type-only имён | 57 | 83 |

Новые runtime: createGraphTrace/graphScene в /graph и createGraphRenderer в
/canvas/graph. Их 22 + 4 типа включают два типа подписей. Root/CJS, private deep
paths, встроенный BFS/DFS и новые режимы/опции Player не добавляются. Прикладные
примеры не являются алгоритмическим API пакета. У GraphEvent четыре закрытых
варианта, у GraphObjects два типа объектов; auto/hidden закрыты, роли — открытые
строки. Новые entry получают общую защиту 1.x при первом выпуске, без статуса
experimental. Фиксированная топология, независимый result, владение payload и
стандартные ошибки согласованы, отложенных решений для первого объёма нет.

## Закрытые замечания

**D1 — устаревший статус релиза.** Текущие справочники ещё называли исправления
1.0, явные шаги/результаты неопубликованными, baseline — 0.16.0, а 1.0.0 — кандидатом.
Согласованы EN/RU-индекс и политика, заголовок support matrix, описание памяти
потока в README и changelog. Исторические отчёты/доказательства кандидатов сохранены
с исходными датами/хэшами; они не переименованы в доказательства 1.1.

**D2 — неполный порядок подписей/ошибок.** Главный справочник пропускал captions
в порядке валидации, а описание метрик смешивало недоступные bounds и неверную
числовую геометрию. Порядок constructor/mark/scene приведён к коду. Отсутствующие/
нечисловые обязательные метрики означают пропуск без приведения типов после проверки
предоставленных чисел; nonfinite числа, отрицательная width и непредставимая
геометрия дают RangeError до пикселей. Исходные host errors и приоритет restore
прежние. Реализация и форма API этой ревизией не менялись.

Открытых замечаний к реализации/API нет в проверенном объёме. Это не доказательство
решения всех шрифтов, размеров графа или будущего редактора топологии.

## Проверки и повторное использование

- Сверены хэши 36 файлов реализации/примеров/тестов/scripts. Все 35 исходников
  релизной базы и восемь export записей совпадают с 3977c78. Package/lockfile/
  зависимости этой ревизией не менялись.
- Повторно использованы [595 тестов / четыре компилятора / 26 bundle-вариантов](../checks/graph-node-captions-implementation-2026-11-17.json):
  исходники реализации/тестов неизменны. TypeScript 5.0.4/5.4.5/5.9.3/6.0.3,
  NodeNext/Bundler, подходящие ES2022/DOM/WebWorker libraries. Новый полный прогон
  suite/compiler/bundle этой ревизией не заявляется.
- Повторно использованы [31 реальная Canvas-проверка + 7 проверок страницы](../checks/graph-node-captions-native-2026-11-17.json)
  с совпадением исходников/снимка. Есть настоящие метрики и независимый pixel oracle
  по графу без подписей. Bitmap ratios 1/1.25/2 — размеры backing store, не три
  масштаба страницы. Старые 15 проверок renderer сохраняют pre-caption scope и
  не прибавляются к новому native-счётчику.
- Добавлены 11 изолированных runtime-проверок: falsy proxy throws, атомарность,
  clone/legacy снимки, Event не читается, hidden-валидация, недоступные/неверные
  метрики, приоритет исходной ошибки и свежий trace.
- Проверены текущий инвентарь экспортов, local links/code parity, git whitespace,
  origin/версии и npm pack --dry-run --ignore-scripts. Свежего registry/latest/
  provenance lookup, native-прогона, benchmark и новой browser-гарантии нет.

Native подтверждает указанные fixtures. Пропуск текста, дискретная смена позиции и
immutable payload приложения — явные ограничения. Бюджет кадра ограничивает чтение
источника, не стоимость одного render графа. Гарантии O(1), FPS, меньших аллокаций
или ускорения не добавлены.

Publish workflow проверяет версии tag/package/lock и запускает package/unit checks,
но сам не требует успеха всех 11 прежних CI jobs. **R3 проверяется до создания
stable Release.** Для существующего ручного релизного gate менять workflow сейчас
не требуется.

Новая правка реализации/API делает соответствующие хэши/приёмку неактуальными.
Только metadata/docs не требуют повторять неизменное рисование, но итоговый
версионный архив и CI проверяются обязательно. Старый успешный CI 1.0 не проверяет
незакоммиченные графовые дополнения.

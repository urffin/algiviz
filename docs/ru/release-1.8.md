# AlgiViz 1.8.0

[English](../release-1.8.md) · [Текущий API](current-api.md) · [Окружения](../support-matrix.md#current-support-boundary)

AlgiViz 1.8.0 добавляет `mapFrame(frame, selectState)` в `/playback`.
Селектор применяется к `previous` и `current` и возвращает данные для
нового кадра. Кадр заморожен на верхнем уровне и сохраняет исходные поля
`progress`, `stepIndex` и `event`. Результаты селектора используются без
копирования. [Проекция кадра](playback.md#проекция-кадра).

Примеры Краскала, BFS и пирамидальной сортировки используют проекцию для
отрисовки синхронных панелей. В пирамидальной сортировке рендерер массива
берёт своё событие `swap` из общего снимка. При перемотке через `stepHistory`
граф, расстояния и очередь в демо Дейкстры используют один целевой снимок.
[Синхронные панели](player-multiple-panels.md) · [Демо Дейкстры](../../examples/dijkstra.html).

У пакета 16 точек входа ESM и нет зависимостей времени выполнения.
Новая функция работает в существующем модуле `/playback` без DOM.

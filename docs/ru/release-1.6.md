# AlgiViz 1.6.0

[English](../release-1.6.md) · [Текущий API](current-api.md) · [Окружения](../support-matrix.md#current-support-boundary)

AlgiViz 1.6.0 добавляет необязательную функцию `itemLabel` в
`createArrayRenderer` и его совместимый псевдоним `createSortRenderer`.
Функция получает отрисовываемый элемент. Используйте его ID, чтобы
различать равные значения при обмене, перемотке и Restart. Без функции
или при возврате `undefined` выводится числовая подпись. Пустая строка
скрывает значение и сохраняет индекс. [Справочник Canvas массива](array.md#подписи-элементов).

В репозитории есть два примера с синхронными панелями в одном Player:

- Алгоритм Краскала показывает исходный граф и растущее минимальное
  остовное дерево. [Пример Краскала](examples.md#минимальное-остовное-дерево-краскала).
- Пирамидальная сортировка показывает бинарную кучу и массив на
  `[2a, 2b, 1]`. Панель массива разводит плитки по высоте при обмене,
  чтобы подписи читались. [Пример пирамидальной сортировки](examples.md#пирамидальная-сортировка-с-player).

Руководство по двум панелям показывает, как хранить один неизменяемый
снимок, проецировать оба конца перехода и сохранять `ArrayEvent` для
полной истории. [Две панели в одном Player](player-multiple-panels.md).

## Миграция и окружения

Существующие приложения могут сохранить импорты и опции рендерера.
У пакета 16 точек входа ESM и нет зависимостей времени выполнения.
Декларациям `/canvas` нужны ES2022 и DOM, а для отрисовки нужен контекст
HTML Canvas 2D. Размеры Canvas и DPR задаёт приложение. Страницы примеров
и алгоритмы находятся в репозитории.

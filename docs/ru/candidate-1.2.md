# Кандидат 1.2.0

[English](../candidate-1.2.md) · [Changelog](../../CHANGELOG.md) · [Текущий API](current-api.md) · [Готовность дерева](tree-readiness-1.2.md)

**Подготовлен 2026-11-19; не опубликован.** package.json и оба корневых поля версии
lockfile содержат 1.2.0. Коммит, добавляющий этот документ, определяет ревизию
кандидата. Этап включает commit/push и ожидание всех 11 CI jobs именно на этом
коммите. Тег v1.2.0, GitHub Release и публикация npm требуют отдельного этапа.

## Состав и миграция

Относительно выпущенной 1.1.0 / 629defe добавлены два независимых ESM-пути:
`/tree` (`createTreeTrace`, `treeScene`, 29 типов) и `/canvas/tree`
(`createTreeRenderer`, четыре типа). Поверхность: двенадцать entry, 27 runtime-имён
и 128 type-only экспортов (116 различных типов).

[Tree API](tree-api.md) определяет корневые ordered/binary деревья, стабильные ID
узлов/связей, атомарный edit топологии, явную раскладку, отметки, подписи и
независимый результат. Выбывшие ID нельзя использовать в той же trace; история
выбывания растёт с числом различных зафиксированных ID независимо от окна
перемотки. Алгоритмы принадлежат приложению. [Tree Canvas](tree-canvas-api.md)
добавляет ordered/binary layout, пустые слоты, прикреплённые crossfade-связи,
безопасные вторичные подписи и зелёный результат. Исправление T1 резервирует
полную обводку нарисованного пустого слота.

**Десяти прежним импортам миграция не нужна.** Их 43 исходника и export-map
записи, runtime-зависимости и версии компиляторов не меняются. Прежние шаги,
кадры, сцены и Player обеспечивают завершение, перемотку, Restart и очистку.
Новых кнопок Player, корневого импорта, CommonJS и обещаний поддержки браузеров
нет. При первой публикации новые entry получают общую политику совместимости 1.x.

После публикации импорты дерева требуют 1.2.0; в npm 1.1.0 обоих entry нет.
До этого нужна локальная сборка/архив. Quickstart поиска минимума намеренно
фиксирует npm 1.0.0 и остаётся воспроизводимым. Новая страница вставки/правого
поворота — пример репозитория рядом с сохранённым собственным обходом; ни пример,
ни универсальный алгоритм дерева не экспортируются пакетом.

## Проверки и оставшиеся этапы

[Отчёт подготовки](../checks/candidate-1.2.0-2026-11-19.json) фиксирует новые
репозиторные тесты, установленный версионный архив, strict consumers
NodeNext/Bundler, изоляцию bundle и хэши файлов. Native-приёмка используется после
проверки идентичности исходников и сборки: 32 проверки renderer и 17 UI-проверок
примера из [native-отчёта T1](../checks/tree-t1-native-2026-11-19.json).
Подготовка metadata/документации не заявляет нового браузерного запуска или замера
производительности.

R0 (T1), R1 (metadata/notes) и R2 (локальный freeze архива) покрыты этими отчётами.
R3 требует всех одиннадцати jobs на итоговом коммите: Node 22/24/26 ×
Ubuntu/Windows (6), TypeScript 5.0.4/5.4.5/5.9.3/6.0.3 consumers (4), bundle
isolation (1). CI прошлого релиза не подтверждает этот кандидат. Результаты CI
проверяются после commit/push; отчёт подготовки их не заявляет.

R4 остаётся отдельным: разрешить тег и стабильный GitHub Release на проверенном
SHA, дождаться OIDC-публикации npm и проверить exact version, latest, свежую
установку и provenance/source SHA. Publish workflow сам не требует предыдущих
одиннадцати jobs. Тег и публикация не входят в эту подготовку.

# План развития AlgiViz

## Canvas-рендерер графа

### Размещение подписей рёбер

Доступно с 1.9.0.

Штатный Canvas-рендерер графа ищет свободное место для подписей вертикальных,
диагональных и пересекающихся рёбер. [Настройка размещения](graph-api.md#размещение-подписей-рёбер)

Пример для проверки — [интерактив «Алгоритм Ахо — Корасика»](https://grundyjs.ru/algorithms/aho-corasick/). Сейчас он использует собственную сцену и рендерер на публичном API AlgiViz.

## Отрисовка графов и деревьев в 1.10.0

Подготовлены `nodeRadius` для обоих рендереров, `drawEdge` и `edgeBend` для
графа, `drawNode` и `doubleOutlineNodeIds` для дерева. Примеры Ахо — Корасика
и Trie проверены во встроенном браузере с перемоткой.
[Заметки к 1.10.0](release-1.10.md)

При миграции интерактивов сайта Ахо — Корасика можно проверить на штатном
рендерере. При переносе Trie нужно сохранить подсказку с полным префиксом.

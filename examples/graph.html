Graph · breadth-first search

Explore an undirected graph with cycles and a disconnected component. BFS discovers each reachable vertex once and computes its shortest distance in edges from the selected start.

Yellow: current vertex and examined edge. Purple: queued. Green: completed vertices and discovery edges. Gray: undiscovered. The dot follows the examined edge; queue entries move when dequeued.

Vertices are marked on enqueue, so cycles and repeated edges do not duplicate work. Only the start component is visited. Restart or change the start to explore another component.

The algorithm, immutable graph state and vertex/connection/queueEntry visualizations belong to this example. AlgiViz supplies playback, cached scene projection and dispatch. No graph API is added to the package.

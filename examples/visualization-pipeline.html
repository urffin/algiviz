Нажмите «Начать», чтобы увидеть создание первого кадра. Затем переходите к следующим состояниям.

Генератор → обработчик → плеер



Результат
Три клика — три новые позиции: 40 → 200 → 360 → 560. Первый снимок создаётся после нажатия «Начать».
Одинаковый id связывает состояния круга. Тип dot выбирает обработчик, обработчик рисует current.data.x без интерполяции.
Показан код движения. Подсветка замедленно воспроизводит записанные вызовы; сам JavaScript выполняется синхронно. Зелёный — обработка, фиолетовый — рисование. HTML: Canvas 600 × 160 и две кнопки с id next и restart. Импорты ниже подключены к локальной сборке через import map.

Плеер из модуля /player, доступного с AlgiViz 0.12.0. Сначала подключите модуль, затем нажмите «Начать» в нужном примере. До этого источники не создаются.

Генератор читается по ходу воспроизведения. Кнопка «Назад» возвращает по последним трём состояниям. Повторный проход окна не читает генератор.

Проверка жизненного цикла

Рисование и вершины задаёт пример, плеер управляет только состояниями.

Код подключения

const { Player } = await import('@grundyjs/algiviz/player');
const ui = new Player(container, {
  viewport: canvas, // Canvas, SVG или собственный DOM-элемент
  source: () => states(),
  rewindCapacity: 3, // сохранять три состояния, включая текущее
  // history: () => savedStates, // вместо source: запись со шкалой
  render: draw,
  // stepDurationMs: 1000, // для авторежима; обязательно для записи
});
// При удалении виджета: ui.dispose();

Пример использует локальную сборку /player с опцией rewindCapacity, добавленной в 0.14.0. Границы доступного окна показаны рядом с меткой «ПОТОК». Без этой опции поток движется только вперёд. Запись получает готовый конечный массив состояний; шкала времени появляется только у записи и скрывается настройкой seekBar: false.

Изображение и панель управления образуют один плеер. Технические кнопки и счётчики спрятаны в «Проверке жизненного цикла»: удаление управления останавливает воспроизведение и сохраняет последний Canvas/SVG.

После начала панель скрывается через две секунды бездействия. Движение мыши, касание или фокус с клавиатуры показывают её снова. Настройка autoHide: false оставляет постоянную панель под изображением.

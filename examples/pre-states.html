Learning: plain states and arbitrary output

A generator supplies three array snapshots: [3,1,2] → [1,3,2] → [1,2,3]. Your callback displays the numbers; AlgiViz provides the controls.

Press Start

Press Start, then Next state twice to reach the sorted snapshot. One more click detects completion. Restart displays the first snapshot again.

The snapshots are written explicitly to introduce playback, not a sorting algorithm. Continue to the minimum-search quickstart · JavaScript source · Next: scenes and interpolation

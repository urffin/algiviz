Появление, движение и удаление объектов

Начните с пустой сцены. «+¼ перехода» вызывает advance() и показывает промежуточный кадр. nextStep() завершает начатый переход либо получает следующее состояние на границе.

ОбъектФазаНаличиеpreviouscurrent

У enter нет previous, у exit нет current. Полностью исчезнувший объект может ещё присутствовать в кадре с наличием 0: обработчик пропускает его отрисовку.

Закройте источник в середине перехода: finally выполнится один раз, последний кадр сохранится. «Сначала» создаёт новый генератор. После последнего состояния нужен дополнительный запрос для обнаружения конца.

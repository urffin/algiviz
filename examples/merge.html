Merge sort with a buffer

An application-owned algorithm and two-row scene using the public scene and playback APIs. The array is divided recursively; sorted halves are merged into a reusable buffer, then copied back.

Up to 24 values, magnitude up to 1000. Letters distinguish equal values.

Frames outline the active halves. Yellow shows comparisons and copies; purple shows buffer copies; green marks the final result. During copy-back, the main row may temporarily contain duplicate copies. Cell identities use row and position rather than element identity.

Left wins ties, preserving stability. Algorithm time is Θ(n log n), extra memory O(n). Stored visualization history costs up to O(n² log n) separately. This example implements merge sort locally; it is not a new package export.
